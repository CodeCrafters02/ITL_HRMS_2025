# App Logo

## Instructions

1. **Place your logo file here** as `app_logo.png`
2. **Requirements:**
   - Format: PNG (with transparency)
   - Size: 1024x1024 pixels (square, 1:1 aspect ratio)
   - Background: Transparent (recommended) or solid color
   - Content: Your logo centered with some padding around edges

3. **After adding the logo**, run:
   ```bash
   flutter pub get
   flutter pub run flutter_launcher_icons
   ```

4. **Rebuild the app:**
   ```bash
   flutter clean
   flutter run
   ```

## Notes

- The logo will be automatically resized for all required icon sizes
- Make sure the logo is recognizable at small sizes (app icons are typically 48-192px)
- After generating icons, you may need to uninstall and reinstall the app to see the new icon
